FitBuddy – AI Fitness Plan Generator
About
FitBuddy is an AI-based web application that generates personalized diet and workout plans based on user details such as age, weight, height, fitness goal, and fitness level.
Features
User fitness information input
Personalized diet plan
5-day workout plan
AI-generated fitness tips
Simple and user-friendly interface
Technologies Used
HTML
CSS
JavaScript
Gemini AI

FitBuddy/

How to Run
Download the project.
Open index.html in a web browser.
Enter your fitness details.
Click "Generate AI Plan".
